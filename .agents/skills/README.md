# Custom Codex skills

Personal skills copied from `~/.codex/skills`, with their supporting references and agent metadata preserved. Codex discovers these repo-scoped skills under `.agents/skills`.

Built-in system skills, plugin-managed skills, and duplicate `.skill` archives are excluded. Install plugins separately for their skills and connected tools.

Some skills are specific to KALM IDE and reference its modules, `.vibe-tools` protocols, or `ide/temp` prompts. Those project files are not included here; use those workflows only when their prerequisites are available. The skill instructions have not been adapted to ExecutableSpecificationLanguage.

To use these skills globally in another environment, copy the individual skill directories into `~/.agents/skills`.
